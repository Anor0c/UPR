**UPR** est un jeu de course / runner multijoueur développé sous **Unreal Engine 5.8** pour Windows.
Les joueurs incarnent des runners (Adler, DDos, Shred…) et enchaînent wall run, grind et escalade
pour atteindre la ligne d'arrivée en premier.

## Prérequis

- Windows 10/11 (64 bits)
- **Unreal Engine 5.8** (installé via l'Epic Games Launcher)
- Visual Studio 2022 (charge de travail « Développement de jeux en C++ ») ou JetBrains Rider
- Plugin **Async Loading Screen** (Fab / Marketplace), à installer dans le moteur
